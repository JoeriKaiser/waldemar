### pin
Stack: Rust  
Link: https://github.com/JoeriKaiser/pin

A local-first, Git-backed work ledger and execution runner in Rust for coding agents and humans. Tasks, bugs, and decisions live as Markdown files with YAML front matter. Agents run in isolated worktrees, claim items on atomic leases, write handoffs, and must attach verification evidence to complete work. Ships a live local web viewer and checksum-verified binaries for Linux, macOS, and Windows.
